# AskBar

The prompt box for asking ergOS about the data on screen. Frosted glass, one line that grows, a tool row with add, attach, a scope chip (the selected plant) and a solid send button.

The mic button hands over to the VoiceBar for real talk. Use `<form class="eg-ask">` with a `<textarea class="eg-ask__input">` and an `eg-ask__bar`. Prevent the native submit and handle it in script. Offer two or three suggestion chips underneath, phrased as questions an operator would ask.
