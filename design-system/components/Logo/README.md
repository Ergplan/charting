# Logo

The jouleWise wordmark in Harmony glass: Urbanist letters with the “o” as a translucent green glass orb (refraction glow, engraved J-and-wave glyph, specular cap, rim light). A classic 2D glass version keeps the original gold and brown.

- Screens: `joulewise-dark.svg` on dark grounds, `joulewise-light.svg` on light grounds. In React swap them with the theme (see the Next.js demo's `components/Logo.tsx`).
- Inside ergOS the product name stays the `.eg-wordmark` type (“erg” + “OS” in accent); the jouleWise logo signs the sidebar foot, login, emails and reports.
- Small sizes (under 120 px wide): the orb `joulewise-mark.svg` or `joulewise-app-icon.svg`.
- Files and rules: `design-system/assets/logo/README.md`.
