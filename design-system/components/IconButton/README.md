# IconButton

Round glass buttons for single-icon actions: back, comment, export, notifications, paging.

- `eg-icon-btn` 48px for screen chrome (top of a mobile screen, toolbar clusters); `--sm` 36px in card headers and date pagers; `--xs` 28px inside inputs.
- `--solid` (ink fill) is the send button of the Ask bar. `--accent` marks an on state such as auto-trading.
- Add `<span class="eg-icon-btn__badge">` for an unread dot.

Always give an `aria-label`; the icon alone is not a name. Keep clusters to four.
