# Fields

Inputs for filtering and parameters: the pill date range, text and select fields, and switches.

- `eg-range`: two date buttons joined by an arrow; each opens a date picker. Always show both ends.
- `eg-field` > `eg-field__label` + `eg-input` (wrapping an `<input>` or `<select>`, with an optional leading icon and trailing unit). Units sit inside the field, muted.
- `eg-switch`: a labelled checkbox for binary settings (auto-trading, lock Y axis).

Focus shows the `focus-ring` border plus a soft accent halo.
